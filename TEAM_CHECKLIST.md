# Demo day checklist

- [ ] Start AWS Academy Learner Lab; use us-east-1 unless instructed otherwise.
- [ ] Confirm the dashboard opens locally or from the S3 website endpoint.
- [ ] Demonstrate green, red, and amber simulation states.
- [ ] If AWS integration is configured, execute the pipeline and verify `status.json`.
- [ ] Capture dashboard, Lambda, EventBridge, S3, and CodePipeline screenshots.
- [ ] Explain the target user, business problem, value, architecture, limitations, and next improvement.
- [ ] Each of the five members explains their own contribution.
- [ ] Check budget and remove only resources that the team is authorized to remove.
